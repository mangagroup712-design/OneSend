# OneSend WebRTC ファイル転送

同じネットワークまたは別ネットワークのブラウザー同士が、受信側の承認後にファイルを直接送るサービスです。ファイル本体は WebRTC DataChannel で端末間を流れ、シグナリングサーバーに保存されません。

## ページ

- `/` - サービス案内
- `/send.html` - ファイル選択・貼り付け、端末選択、テキスト／URL共有、送信進捗、折り畳み式の速度改善ヒント
- `/receive.html` - 端末名・任意のPIN設定、全画面の受信承認、正確な受信進捗、プレビュー、テキスト履歴、ZIP一括ダウンロード

## 使い方

1. 受信側で `/receive.html` を開き、端末名を設定します。必要ならPINを有効にします。
2. 送信側で `/send.html` を開いてファイルを選ぶか貼り付け、受信端末を選び「送信」ボタンを押します。
3. 受信側で送信元、ファイル名、容量、件数を確認し、「受け取る」か「拒否」を選びます。要求は30秒でタイムアウトします。PIN設定中は送信側に入力欄が表示されます。
4. 承認後にファイル本体をブラウザー間で直接転送します。送信進捗は受信完了の確認まで最大99%で表示します。

WebRTCモードの受信側は、部屋に参加した後、送信側が接続するまで部屋の有効期限（15分）まで待機します。

クリップボードに入っているテキストや画像なども直接Ctrl+Cなどで追加できます。テキストやURLは共有欄へ貼り付け、端末を選んで送信します。受信テキストの履歴は受信画面のメモリ上だけに保持されます。


## 転送の仕組みと速度

送信側は `file.slice()` でファイルを64KBずつ `ArrayBuffer` に読み、DataChannelの `bufferedAmount` が4MiBを超えないよう待機しながら送ります。受信側はOPFSが使える場合は一時ファイルへ保存し、使えない場合はメモリへ保持します。複数ファイルは選択順に連続転送します。1ファイルの容量上限は2GBです。

転送を速くするには、有線LANを使う、Wi-Fiルーターの近くで5GHz／6GHz帯を使う、他の大容量通信・VPN・ゲストWi-Fiを避ける、省電力モードを解除して画面を前面に保つ方法があります。遅い状態が続く場合は、端末・ブラウザー、Wi-Fi帯域、表示速度、ファイル数と容量をもとに追加の改善を検討してください。

ブラウザーはOSの端末名やLAN上の全端末を直接読み取れません。OneSendの受信画面を開いて待機中の端末を一覧にし、表示名は利用者が設定します。「この端末を一覧に表示する」をオフにすると部屋コードによるWebRTCモードだけで受信できます。IPv4とIPv6が混在するネットワークでは、端末一覧で互いを検出できないことがあります。
携帯回線などのCGNATでは複数の利用者が同じネットワークとして扱われ、端末一覧に他人の端末が表示される場合があります。不明な端末は選択せず、必要に応じて一覧表示をオフにして部屋コードを利用してください。

## セキュリティと制限

- 受信側の承認後に接続します。PINは確立した暗号化WebRTCチャネル内で照合し、PIN自体をシグナリングAPIへ送信しません。
- WebRTCモードの部屋コードは6桁数字です。参加時に役割ごとの一時トークンを発行し、以後のシグナリングはそのトークンで認証します。同じ役割の二重参加はできません。部屋は最後の通信から15分で失効し、作成・参加の失敗回数にも制限があります。
- ファイル本体はシグナリングサーバーを通りません。TURNを設定すると、直接接続できない対称NAT・モバイル回線でもCloudflare Realtime TURNで中継できます。中継時は速度が低下する場合があります。未設定・資格情報取得失敗時はGoogle公開STUN `stun:stun.l.google.com:19302`のみで従来どおり動作します。

## Cloudflare TURN の設定

Cloudflare Realtime TURN のキーを作成後、秘密値はリポジトリに保存せず次のように設定します。

```powershell
npx wrangler secret put TURN_KEY_ID
npx wrangler secret put TURN_KEY_API_TOKEN
```

Worker は短期資格情報（1時間）を発行します。秘密値が未設定でもローカルの `npm start` と本番WorkerはSTUNフォールバックで動作します。

`/api/ice` は同一オリジンからのみ利用でき、TURN資格情報の発行回数にも制限があります。端末一覧を使わない場合は、受信画面の「この端末を一覧に表示する」をオフにしてWebRTCモードを利用してください。

## ローカル確認

```powershell
npm start
npx wrangler dev
```

ローカルの `serve.mjs` はメモリ実装で、部屋・端末一覧の期限切れ、役割トークン、部屋削除も本番Workerと同じように扱います。
